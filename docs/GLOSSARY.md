# Glossary

- **Clip:** one generated output (audio + transcript + character id + timestamp).
- **Character:** a voice model plus FX preset plus avatar, defined in the character registry.
- **STT:** speech-to-text (turning the user's audio into text).
- **TTS:** text-to-speech (speaking text in a character voice).
- **Voice conversion (VC):** changing the voice of the user's audio directly, without going through text.
- **PWA:** Progressive Web App; installable, works offline.
- **ADR:** Architecture Decision Record.
